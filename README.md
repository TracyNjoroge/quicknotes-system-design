# QuickNotes System Design

## Description

QuickNotes is a simple notes application built with HTML, CSS, and JavaScript. It uses the JSONPlaceholder API to practise making GET, POST, and DELETE requests.

The project also includes system design documents covering API design, database modelling, and application architecture.

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using the Live Server extension.
4. Click "Load Notes" to fetch notes from the API.
5. Use the form to create notes and the Delete buttons to remove them.

Note: JSONPlaceholder simulates creating and deleting notes. These changes are not permanently saved on the server.
